📌 Salesforce Assignment 8: Email Notification with Attachment (Console Based)

🎯 Objective

Develop a console-based Apex program that sends an email notification with an attachment to a specified email address using Salesforce email services.

🛠️ Features
- Sends Email using Apex `Messaging.SingleEmailMessage`
- Defines Recipient, Subject, and Body
- Attaches a dynamically generated Text file to the email
- Executed via Developer Console

⚙️ Technologies Used
- Apex (Backend Logic)
- Developer Console (Execute Anonymous)
- Salesforce Email Services

🚀 Steps Performed
1. Enabled Email Deliverability in Salesforce Setup
2. Developed Apex Class (`EmailWithAttachment`)
3. Executed via Developer Console
4. Verified receipt of email with the attachment in Gmail

✅ Result

Successfully implemented a console-based Apex program to send an email with an attachment.
