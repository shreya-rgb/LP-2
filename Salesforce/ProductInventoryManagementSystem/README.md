📌 Salesforce Assignment 6: Product Inventory Management System

🎯 Objective

To develop an application in Salesforce using Apex and Visualforce to manage Product Inventory records.

🛠️ Features
- Add Product
- View Product List
- Delete Product

⚙️ Technologies Used
- Apex (Backend Logic)
- Visualforce (UI)
- Salesforce Platform

🚀 Steps Performed
1. Created Custom Object: Product Inventory (`Product_Inventory__c`)
2. Added fields:
   - Product Name (Text)
   - Serial No (Number)
   - Manufacture Date (Date)
   - Expiry Date (Date)
3. Developed Apex Controller (`ProductController`)
4. Created Visualforce Page (`ProductPage`)
5. Implemented:
   - Add Product
   - Display Products
   - Delete Product
