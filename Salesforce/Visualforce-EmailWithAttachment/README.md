📌 Salesforce Assignment 9: Email Notification with Attachment (Visualforce Frontend)

🎯 Objective

Develop an Apex program with a Visualforce frontend that sends an email notification to a specified email address using Salesforce email services. The program handles attachments and displays an error message on the frontend if an invalid email ID is provided.

🛠️ Features
- Visualforce Page for entering Email, Subject, and Body
- Apex Controller to handle the backend email sending logic
- Validation for invalid email ID formats
- Dynamically attached file generated via Apex
- Success and Error messages displayed directly on the UI

⚙️ Technologies Used
- Apex (Backend Logic)
- Visualforce (Frontend UI)
- Salesforce Email Services

🚀 Steps Performed
1. Enabled Email Deliverability in Salesforce Setup
2. Developed Apex Controller (`EmailSenderController`) with email validation and attachment logic
3. Created Visualforce Page (`EmailSenderPage`) for user input
4. Tested sending valid and invalid emails via the Visualforce UI

✅ Result

Successfully implemented an Email Sender application with a UI and validation.
