📌 Salesforce Assignment 5: Bank Account System (Console Based)

🎯 Objective

To create a menu-driven Bank Account System that manages Customer records in Salesforce using Apex (Console Based).

🛠️ Features
- Add Customer
- View All Customers
- Search Customer by ID
- Update Customer
- Delete Customer
- View Records in Lightning UI

⚙️ Technologies Used
- Apex (Backend Logic)
- Developer Console (Execute Anonymous)
- Lightning Experience (Record Visibility)
- Salesforce Platform

🚀 Steps Performed
1. Created Custom Object: Customer
2. Added fields:
   - Customer ID / Emp ID (Auto Number)
   - Customer Name / Emp Name
   - Email
   - Birth Date
   - Department (Picklist)
3. Developed Apex Class (CustomerManager)
4. Created Custom Tab for Customer object
5. Executed all CRUD operations via Developer Console (Anonymous Apex)
6. Viewed records in Lightning Experience

✅ Result

Successfully implemented a Console-Based Bank Account System in Salesforce using Apex with Lightning visibility.
