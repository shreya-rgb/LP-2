📌 Salesforce Assignment 4: Employee Management System (Console Based)

🎯 Objective

To create a menu-driven Employee Management System using Salesforce Apex (Console Based via Developer Console) with Lightning visibility.

🛠️ Features
- Add Employee
- View All Employees
- Search Employee by Emp ID
- Update Employee
- Delete Employee
- View Records in Lightning UI

⚙️ Technologies Used
- Apex (Backend Logic)
- Developer Console (Execute Anonymous)
- Lightning Experience (Record Visibility)
- Salesforce Platform

🚀 Steps Performed
1. Created Custom Object: Employee
2. Added fields:
   - Emp ID (Auto Number — EMP-0001, EMP-0002, ...)
   - Emp Name
   - Email
   - Birth Date
   - Department (Picklist)
3. Developed Apex Class (EmployeeManager)
4. Created Custom Tab for Employee object
5. Executed all CRUD operations via Developer Console (Anonymous Apex)
6. Viewed records in Lightning Experience (App Launcher → Employees)
